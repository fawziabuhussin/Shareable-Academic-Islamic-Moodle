# Old Grades Migration

This folder contains the scripts and data files for importing historical course grades from the old platform.

## Files

| File | Description |
|------|-------------|
| `seed-courses.ts` | Creates the 30 courses in the DB (skips existing ones) |
| `courses-output.csv` | Generated by `seed-courses.ts` — maps course numbers to DB UUIDs |
| `OldGrades.csv` | Historical student grades (format: `Grade,CourseNumber,ID,Bonus,FinalGrade`) |
| `seed-old-grades.ts` | Reads both CSVs and inserts grade records into the `OldGrade` table |

## How It Works

### Step 1 — Seed Courses

Run `seed-courses.ts` to create the courses in the database. This can be run locally (pointing to the remote DB URL) or as part of the production deployment pipeline.

```bash
cd apps/api
npx tsx prisma/old-grades-migrations/seed-courses.ts
```

- Skips courses that already exist (matched by title)
- Generates/updates `courses-output.csv` with the course number → UUID mapping

### Step 2 — Seed Old Grades

Run `seed-old-grades.ts` to import the historical grades. In production, this runs automatically on every deployment via `vercel-migrate.js`.

```bash
npx tsx prisma/old-grades-migrations/seed-old-grades.ts
```

- Reads `courses-output.csv` to resolve course numbers to UUIDs
- Reads `OldGrades.csv` for the grade data
- Uses `createMany({ skipDuplicates: true })` so it's safe to re-run

### Production Deployment

Both scripts run automatically on every production deploy (see `scripts/vercel-migrate.js`):

1. `prisma migrate deploy` — applies pending migrations
2. `seed-courses.ts` — ensures all courses exist
3. `seed-old-grades.ts` — imports old grades (skips duplicates)

## Adding New Old Grades

To import additional historical grades:

1. Append new rows to `OldGrades.csv` (keep the same format: `Grade,CourseNumber,ID,Bonus,FinalGrade`)
2. If new course numbers are introduced, add them to the `courses` array in `seed-courses.ts`
3. Commit and deploy — the next deployment will automatically pick up the new rows
